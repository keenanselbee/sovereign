# HOW TO------------------------------------
Editing models in Blender:
    1. import .flver with soulstruct into blender
    2. export as .fbx, make sure to set game and directory in scene settings
    3. import fbx into .flver with FLVER Editor X2.6 (different program than FLVER Editor 2.4)
    4. use FLVER Editor 2.4 to delete original mesh
    5. use bounding box calculator patch on .flver
