Cave of Knowledge ground message
================================

This guarded native recipe removes Message region 100 (message 2020, SFX 30) from
`m18_00_00_00.msb.dcx`. That region owns the ground glow and interactable hint at
the tutorial entrance. It does not alter the spirit conversation or other tutorial
messages. Run it with the current repository map, matching saved Smithbox map, a
new candidate directory, and the configured Smithbox tools directory. The recipe
checks an unchanged native roundtrip and full decoded preservation before producing
the candidate; game acceptance remains separate.
